Demo importer, wishlist, newsletter providers and consent-aware analytics for the Freshtastic Food Hub theme.

== Description ==

* Safe, repeatable demo importer with tagged content and a cleanup tool that never touches orders, customers or your own content.
* Newsletter signups with consent records, forwarded to Mailchimp, Brevo or Klaviyo from the server (API keys never reach the browser).
* GA4, Google Tag Manager, Meta Pixel and Google Ads purchase conversion with GA4-format ecommerce events, Consent Mode v2 and duplicate-plugin detection.
* Wishlist for guests (browser storage) and customers (account), with a shortcode and My Account tab.
* Testimonials post type and sample-content labels.

== Installation ==

Upload nexora-commerce-toolkit.zip in Plugins → Add New → Upload Plugin and activate. WooCommerce is downloaded, installed and activated automatically (or, if your host blocks automatic installs, a notice offers a one-click install). Then go to Tools → Freshtastic Demo Content or Settings → Freshtastic Toolkit.
